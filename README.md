## 설치

[**최신 릴리즈**](https://github.com/qkr132-lab/nais3-custom/releases/latest)에서 `nais3-custom-x.x.x-setup.exe`를 받아 실행하세요.

- 커스텀판의 데이터는 `%APPDATA%\NAIS3 Custom`에 저장합니다. 기존 커스텀판을 업데이트하면 같은 데이터 폴더를 계속 사용합니다.
- 공식 NAIS3와 데이터 폴더를 분리하며, 처음 실행할 때 기존 데이터 이관을 지원합니다.
- **자동 업데이트**를 지원합니다 — 새 버전이 나오면 앱이 알아서 받아 설치하고, 토큰·설정은 유지됩니다.
- NovelAI 구독과 API 토큰이 필요한 건 공식판과 동일합니다.

## 공식 NAIS3에 추가된 기능

### 씬 모드
- **씬별 검열 설정** — 선택한 씬에 일괄 적용, 적용 상태 표시, 기본 가중치 2.0 및 슬라이더 조절
- **항문 성행위 억제 ON/OFF** — 흰색 검열과 별도로 네거티브에 억제 태그 적용 (기본 OFF)
- **캐릭터 배치 편집** — 자리·역할 배정, 넓게 배치, 다중 선택과 정렬
- **프롬프트 3분할 동기화** — 프리셋 변경과 예약 프롬프트에 최신 편집 내용 반영
- **큐 반복** — 캐릭터/캐릭레퍼/바이브 조합을 바꿔가며 예약 전체를 반복 생성
- **씬별 캐릭터 추가** — 특정 씬에만 캐릭터/레퍼런스 추가 적용 (다중 씬 일괄 가능)
- **씬별 Variety+** — 씬마다 개별 적용 (카드에 배지 표시)
- **선택 예약** — 편집 모드에서 고른 씬들만 예약 ±/일괄 복제, Shift+클릭 범위 선택
- 생성 중 씬마다 남은 개수 실시간 표시, 생성 중 + 누르면 바로 큐에 이어붙음, 취소 시 남은 예약 자동 복원

### 안전장치
- **씬 휴지통** — 삭제 복원, 보관 기간 설정 + **Ctrl+Z 연속 실행취소**
- 이미지 삭제는 Windows 휴지통으로 (영구삭제 아님)
- **매일 자동 DB 백업** — 용량 상한 설정 가능

### 태그
- **한글 태그 자동완성** — 100만여 개 태그를 오프라인 검색하며 한글 뜻·별칭 23,332개 지원 (한글이 연결된 태그 14,712개)
- **초성·부분 입력·연관어 검색** — `ㅈ`, `전신`, `카메하메하`, `에네르기파` 등으로 관련 태그 추천. 전체 태그가 한글 번역된 것은 아닙니다.
- **추천과 사용 기록을 한 목록으로** — 검색 관련도 우선, 최근·자주 사용한 태그를 함께 표시
- **Enter 한 번으로 삽입** — 한글 조합 확정과 검색을 기다려 적용. Shift+Enter 줄바꿈, Ctrl+Z 되돌리기
- 바깥 클릭 시 제안창 닫기, 중첩 배치 창에서 선택, 실수 클릭 방지 개선
- **태그 탐색기** — 신체/의상/악세서리 등 카테고리별로 태그를 둘러보고 클릭 삽입

### 그 밖에
- 캐릭터 카드에 **레퍼런스 연결** (캐릭터 포함 시 자동 적용, 대형 설정 창)
- **내장 브라우저** (단부루/태그 사전 퀵링크, 프록시 설정)
- **이미지 라이브러리** (참고 이미지 모음, 메타데이터/i2i/태그 분석)
- 이미지를 **드래그로 밖에 저장** (드래그 중 창 투명 + 클릭 통과)
- 메타데이터 창 가독성 개선 (항목별/전체 복사)
- 스타일 태그 분석 (Kaloscope)

## 빌드

```bash
npm install
npm run build:win   # Windows 설치본 (dist/)
```

`npm install`/`npm ci`는 버전이 고정된 검색 사전을 내려받아 압축을 풀고,
`resources/tag-search-manifest.json`의 크기와 SHA-256을 확인합니다.
앱의 태그 검색은 네트워크 없이 동작합니다. 설치 스크립트를 건너뛰었다면
빌드 전에 `npm run prepare:tag-search`를 실행하세요.

데이터 출처·라이선스·재생성 방법은 [NOTICE-tag-search.md](NOTICE-tag-search.md)를 참고하세요.
